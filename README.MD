    # Temporizador utilizando a técnica Pomodoro
Aplicação web simples em JavaScript puro que executa um contador regressivo, alternando entre tempo para realizar a tarefa e tempos de descanso, utilizando a técnica Pomodoro.

![Preview da Aplicação](./docs/preview.png)

## Funcionalidades

- [x] Contagem regressiva de 25 minutos para o tempo para a tarefa
- [x] Contagem regressiva de 5 minutos para o tempo para o descanso
- [x] Contagem regressiva de 30 minutos para o tempo para o descanso após a execução de 4 pomodori.
- [x] Botão Como Funciona? para explicar a técnica.
- [x] Bloqueio automático do botão Iniciar durante a execução do timer
- [x] Alerta sonoro ao finalizar o tempo

## Tecnologias Utilizadas

- **HTML5** 
- **CSS3** 
- **JavaScript**
